# SEI 解析诊断（2.5.1）

在录像首页点击「SEI 诊断」，或打开设备的 `/sei-diagnostics`。
选择归档视频后点「开始解析」。也可填写 `/archive/.../*.mp4` 路径。
页面沿用查看器登录权限，只允许读取归档区内的 MP4。

诊断直接调用云上传端使用的 `parse_telemetry(stride=1, missing_ap_unknown=True)`，不使用遥测缓存。
报告包含程序版本与源码 SHA-256、文件路径与大小、MP4 moov 与 H.264 轨道识别、
扫描帧数、NAL/SEI 数量、特斯拉标记命中数、Protobuf 字段出现次数、前五条原始字节与
解码消息、前十条车辆采样、字段范围及解析总耗时。可下载 JSON 或使用浏览器打印。
报告在扫描完成后一次性显示；同一时间仅允许运行一个网页诊断。

- `available`：读到遥测及 AP 状态字段；不表示 FSD 一定处于启用状态。
- `no_ap`：读到遥测，但所有采样都没有 AP 状态字段。
- `no_sei`：当前解析器未提取到遥测。结合 moov、轨道、SEI 和标记计数判断原因，不能据此断定原文件没有 SEI。
- `parse_error`：解析抛出异常，报告保留已完成阶段的统计与错误信息。

当前解析器支持 H.264，每段最多索引 4000 帧；报告明确显示该上限。
缺失字段为 null，不等于实测为零或刹车未踩。报告包含原始遥测及文件路径，按需分享。

本地验证样本 `2026-11-08_13-53-10-front.mp4`：38,511,133 字节，29.2488 秒，
1054 帧、1054 个 SEI NAL、1054 次标记命中和解码成功，结果 `no_ap`。
耗时是运行诊断的主机实测，不能当作 Pi 性能结果。
